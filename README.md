# Kits-FFGZ (摸鱼神器 & 养生指南)

👋 嗨，打工人们！是不是写代码写到头秃？是不是久坐坐到腰间盘突出？
**Kits-FFGZ** 就是为了拯救你的发际线和老腰而生的！它不仅能让你敲 console.log 快得像闪电，还能像老妈一样唠叨你起来喝水。

## ✨ 这是什么神仙功能？

### 🚀 也就是帮你省点力气 (效率工具)

#### 1. 极速打印大法 (`Alt + C`)
还在手敲 `console.log`？out 了！
- **懒人模式**：光标在哪就打哪，或者选中啥就打啥。
- **影分身之术**：支持多光标，一次打十个 log 不是梦。
- **自带皮肤**：打印出来的 log 自带背景色，在控制台里最靓的仔就是你。

#### 2. 英语不灵光拯救者 (`Alt + X`)
变量名看不懂？注释像天书？
选中它，按一下，**Bing 翻译** 立马告诉你这是啥意思。再也不用切浏览器查单词了，偷偷变强惊艳所有人。

#### 3. 毁尸灭迹 (`Alt + D`)
代码写完了，满屏的 `console.log` 看着心烦？
一键删除！瞬间清爽，仿佛那些 bug 从未存在过。
*(还有个 `Alt + V` 可以清除空行，强迫症福音)*

### ❤️ 你的私人健康管家
- **定时唠叨**：默认每 30 分钟即提醒你：“大哥/大姐，歇会儿吧，起来走两步！”
- **每日问候**：定个时间，每天准时可以提醒你（比如提醒该去抢饭了）。

## ⌨️ 快捷键 (背下来，你可以去装杯)

| 连招 | 技能名 | 效果描述 |
| :--- | :--- | :--- |
| `Alt + C` | 召唤 Log | 给你选中的东西打个 Log |
| `Alt + X` | 召唤翻译 | 哪里不会点哪里 |
| `Alt + D` | 一键清空 | 把所有 log 扔进垃圾桶 |
| `Alt + V` | 空间压缩 | 把多余的空行都挤掉 |

记不住？`Ctrl + Shift + P` 输入 `reminder`，都在那里躺着呢。

## ⚙️ 调教指南 (配置)

想让插件更听话？去 `settings.json` 里盘它：

| 设置项 | 默认是啥 | 它是干嘛的 |
| :--- | :--- | :--- |
| `reminder.userName` | `"ffgz"` | 改成你的名字，让它叫得亲切点 |
| `reminder.suffix` | `"·"` | Log 里的前缀，想加个骚气的表情也行 |
| `reminder.fixStyle` | `color:#fff...` | Log 的样式，支持 CSS，整花哨点！ |
| `reminder.reminderTime` | `30` | 多久唠叨你一次（分钟） |
| `reminder.dailyReminderTime` | `18:00` | 每天几点喊你下班 (格式 HH:mm) |
| `reminder.isCursor` | `false` | 开启后，不用选中，光标在哪直接识别单词 |
